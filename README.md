## 🌟 What is RiskTrace?

RiskTrace is an evidence-first financial risk investigation copilot engineered for GCC Banking and NBFC compliance teams. 

Rather than functioning as a generic AI chatbot, RiskTrace transforms financial risk management by combining **Snowflake dynamic tables, deterministic signal detection engines, automated evidence lineage graphs, regulatory grounding, and human-in-the-loop audit reporting**.

### 🎯 Key Differentiator: "PROVE THIS FINDING"
Every statement generated by RiskTrace is backed by clickable, immutable evidence:
- **Transaction Evidence:** Trace amounts, counterparty velocities, and transfer speeds directly back to Snowflake transaction records.
- **Statistical Evidence:** Inspect baseline calculations (e.g. 8.4x baseline deviation over a 30-day window).
- **Regulatory Grounding:** Link finding criteria directly to RBI circulars, FATF recommendations, or Basel III standards.
